# 🌸 Chúc Mừng Ngày Phụ Nữ Việt Nam (20/10) - Vietnamese Women's Day

Một trang web tĩnh tương tác hiện đại, tinh tế và sinh động chúc mừng **Ngày Phụ nữ Việt Nam 20/10**. Được thiết kế để gửi gắm trọn vẹn yêu thương, lòng biết ơn và sự trân trọng tới những người phụ nữ tuyệt vời nhất.

---

## ✨ Điểm Nổi Bật & Tính Năng

- 🌺 **Hiệu ứng đồ họa sống động**:
  - Cánh hoa hồng bay trong gió, ngôi sao lấp lánh và trái tim bay bổng bằng Canvas 2D mượt mà.
  - Pháo hoa tim và hoa nở bùng nổ khi chạm/click vào bất kỳ điểm nào trên màn hình.
  - Đóa hoa hồng 3D tương tác nở rộ và gửi gắm thông điệp ngẫu nhiên.
- 💌 **Bức thư & Phong bì 3D tương tác**:
  - Chạm vào con dấu xi để mở phong thư với hiệu ứng mở nắp và rút thư 3D chân thực.
  - Chứa bức thư tay ấm áp cùng lời chúc ý nghĩa.
- 📜 **Thư viện lời chúc phong phú theo chủ đề**:
  - Lời chúc dành cho **Mẹ**
  - Lời chúc dành cho **Người yêu / Vợ**
  - Lời chúc dành cho **Chị / Em gái**
  - Lời chúc dành cho **Bạn bè & Nữ đồng nghiệp**
  - Hỗ trợ đổi lời chúc ngẫu nhiên, sao chép nhanh vào bộ nhớ tạm hoặc đưa thẳng vào phong thư.
- 🎁 **Cá nhân hóa thiệp & Chia sẻ liên kết**:
  - Nhập tên người nhận và người gửi để thiệp tự động cập nhật tên riêng.
  - Tạo link chia sẻ (URL params: `?to=...&from=...`) gửi qua Zalo, Messenger, Facebook để người nhận mở ra thấy ngay tên mình!
- 🎶 **Âm nhạc du dương (Web Audio API)**:
  - Tích hợp giai điệu êm dịu, ấm áp bằng Web Audio API không phụ thuộc file ngoài, hoạt động 100% offline và ổn định trên mọi thiết bị.
  - Nút bật/tắt nhạc nổi góc màn hình cùng hiệu ứng sóng nhạc sinh động.
- 📱 **Giao diện Responsive**:
  - Tối ưu hoàn hảo cho điện thoại thông minh, máy tính bảng và màn hình máy tính lớn.

## 🚀 Trải Nghiệm & Cài Đặt

### 1. Xem trực tiếp trên máy (Offline)
Bạn chỉ cần mở trực tiếp file `index.html` bằng bất kỳ trình duyệt nào (Chrome, Safari, Edge, Firefox):
```bash
# Double click vào index.html hoặc mở bằng lệnh:
start index.html
```

### 2. Kích hoạt GitHub Pages để nhận link trực tuyến miễn phí
1. Truy cập vào kho mã nguồn trên GitHub: [VietNamWomanDay Repository](https://github.com/Huynguyen382/VietNamWomanDay)
2. Nhấn vào tab **Settings** > chọn mục **Pages** ở thanh bên trái.
3. Tại phần **Build and deployment**:
   - **Source**: Chọn `Deploy from a branch`
   - **Branch**: Chọn nhánh `main` (hoặc `master`) và thư mục `/(root)`
   - Nhấn **Save**.
4. Sau khoảng 1-2 phút, GitHub Pages sẽ cung cấp cho bạn một đường link trực tuyến dạng:
   `https://Huynguyen382.github.io/VietNamWomanDay/`

## 🛠️ Công Nghệ Sử Dụng

- **HTML5**: Cấu trúc ngữ nghĩa chuẩn SEO, Meta tags Open Graph chia sẻ mạng xã hội.
- **CSS3 Modern**: CSS Grid, Flexbox, 3D Transforms (`perspective`, `rotateX`), Glassmorphism, Keyframe Animations.
- **JavaScript (ES6+)**:
  - Canvas 2D Context Particle Engine (vật lý cánh hoa, gió, trọng lực).
  - Web Audio API (tổng hợp âm thanh nhạc thư giãn & hiệu ứng chuông).
  - Clipboard API, URLSearchParams.
- **Google Fonts**: `Dancing Script`, `Playfair Display`, `Quicksand`.
- **Font Awesome 6**: Bộ icon vector sắc nét.
